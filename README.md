# Nexus MTK Tool (Professional Edition)

An advanced desktop application designed for MTK device operations, built with Python, Tkinter, and custom hardware-locked licensing (HWID).

## Features
- BROM/VCOM Communication
- Scatter Parsing
- NVRAM Backup & Restore
- FRP Bypass support
- Hardware-locked security system (HWID Protection)

## Requirements
- Python 3.10+
- PySerial
